# dsh-jand 0.5.1

- 协作详情显示当前目标、双方的消息摘录及待回复请求，支持按页向前读取聊天记录。
- 设置页显示本地协作统计，区分仅邀请记录、已有交流记录和统计不可用状态。
- 默认统筹上限为 1。阶段内的任务都已结算、受管运行已结束时，插件会清理统筹会话。确认退出后才释放名额，退出状态不明时保留名额。
- 本版固定使用 Jand 0.5.0。内核首次使用时按平台下载，并核对归档和二进制的 SHA-256。

## 安装

1. 运行 `npm pack @xiaomao361/dsh-jand@0.5.1`，解压得到的 `xiaomao361-dsh-jand-0.5.1.tgz`。
2. 在目标 DeepSeek Harness 会话中授权安装解压得到的 `package` 目录，请 DSH 使用 `install_bundle`。
3. 重新加载该 profile，在设置中打开「jand 协作」查看内核与中继状态。可以在聊天中发起或接受协作。

保留上一版安装包以供回退。插件运行数据存放在包外。已有数据目录使用自定义容量时，以该目录的实际配置为准。

## 验证范围

在 DeepSeek Harness 0.2.1-rc.5、macOS arm64 和公共 Relay 上，用隔离数据目录完成两轮真实模型协作。第一轮统筹自然释放后，第二轮在默认单槽下直接启动并结算。第一轮有一次超出只读约定的临时文件写入，第二轮按约定执行。桌面验收使用源码加载，安装包的页面视觉和其他平台实机交互仍待验收。
