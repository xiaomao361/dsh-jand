# 协作详情 0.5.1

首页配置与统计保持 0.5.0 的交互。本次纠正详情仍为事件列表的问题。

## 阅读顺序

1. 顶部协作摘要：当前目标、双方最新消息摘录（注明消息类型与说话方）、未答复请求。记录不完整时明确提示。
2. 聊天记录直接可见：对方在左，我方在右；每条标明说话方、时间、消息类型。加入、暂停、结束等系统事件居中弱化，详细说明可展开。
3. 默认最近十条，按本机记录顺序从早到晚排列。顶部“加载更早”每次前置十条，保留已显示消息和展开状态。长消息展开查看全文，消息取代关系仍保留。
4. 本次统计、完整目标和技术信息在下方折叠。

摘要为本机当前目标下消息的可归属摘录，不调用模型，不上传记录，不声称语义综合或任务验收；双方完成声明仍标明来源。旧目标的完成声明不混入当前摘要。

安装与验证范围见 [0.5.1 发布说明](RELEASE_0.5.1.md)。
